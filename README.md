# ⛳ YDC 골프 내기 — Golf Bet Tracker

필드에서 쓰는 **100% 오프라인** 골프 내기 정산 앱입니다.
홀마다 자동 저장되고, 돈 계산은 매번 **기록(history)에서 처음부터 다시 계산**하기 때문에 누적 금액이 틀어지지 않습니다.

- 라이브: <https://lukezax71-cyber.github.io/Ydc-golf-bet/>
- 만든 사람: 조영덕 · Brian Cho (기존 ydcgolf.com 규칙 그대로)
- 아이폰: 사파리로 열고 **공유 → 홈 화면에 추가** → 앱처럼 실행 (비행기 모드에서도 동작)

---

## 왜 다시 만들었나

기존 앱은 실시간 동기화(`workers.dev`) 서버와 연결돼 있어서, 신호가 약한 골프장에서

- 중간에 화면이 멈추거나
- 정산 금액이 어긋나는 일

이 있었습니다. 이 버전은 **네트워크 요청을 한 번도 하지 않습니다**(서버·WebSocket·동기화 코드 없음).

## 핵심 설계

| 원칙 | 내용 |
|---|---|
| 단일 원천 | 라운드의 `history`(홀별 타수 + 사이드 결정)와 `initialPlayers`만 저장하고, `net`·`points`·남은 더블·이월 횟수·오너 순서는 **항상 다시 계산**합니다. |
| 즉시 저장 | 화면을 바꾸는 모든 동작 뒤에 `localStorage`에 저장하고, 같은 내용을 `IndexedDB`에도 백업합니다. 입력 중인 타수(draft)까지 저장되어 사파리를 닫아도 복구됩니다. |
| 되돌리기/수정 | 마지막 홀을 취소하거나 수정하면 그 기록을 지우고 전체를 다시 계산합니다. 배율·이월·더블도 함께 되돌아갑니다. |
| 결과 공유 | 정산을 카톡용 텍스트로 복사하거나, 순위·정산이 담긴 결과 카드(PNG)를 만들어 저장/공유합니다. |
| 야외 UI | 390px 기준 큰 버튼(52px 이상), 햇빛 아래서도 읽히는 고대비, 라이트/다크 테마. |

## 규칙 (기존 앱과 동일)

**공통**

- 기본 정산: 모든 짝이 `(타수 차) × 기본 배팅 × 배율` 로 정산하고, 마지막에 **최소 이체**로 상계합니다.
- 언더파 보너스: 버디 `-1` ×1, 이글 `-2` ×5, `-3` ×10 — 나보다 못 친 모든 사람에게 각각 받습니다.
- 니어/롱기: 지정 홀 승자에게 `(이월 + 1) × 기본 × 배율` (여러 명이면 나눠 받음). 무승자·지우개면 **지금 정산 / 이월(+1) / 이월 초기화**를 고릅니다.
- 오너 순서: 직전 홀 타수 순 → 동타면 앞 홀로 거슬러 비교 → 그래도 같으면 처음 순서.
- YDC 모드 라운드 최종 정산: **총 타수 차이 × 기본 배팅** (잘 친 사람이 못 친 사람에게). 홀 정산과 별도로 더해집니다.
- 오장(스탠다드) 모드는 라운드 최종 정산이 없습니다.

**다음 홀 배율**

- YDC (가장 큰 하나만): 전원 파 ×10 · 전원 같은 타수 ×5 · 스트레이트 ×5 · 3명 동타 ×3 · 2명 동타 ×2 · `-1` 이하 또는 `+3` 이상 ×2
- 오장: 언더파 · `+3` 이상 · 최저 타수 동타 → ×2, 그리고 개인별 **더블 2회**(1홀 1회, 이미 2배인 홀에서는 사용되지 않음)

## 사용법

1. **새 라운드 시작** → 모드(YDC/오장) · 기본 배팅 · 인원(2~4) · 홀 수(9/18) · 이름 · 니어/롱기 홀 지정
2. 각 홀에서 `−` / `+` 또는 숫자를 눌러 타수 입력 → `홀 완료`
3. 결과 화면에서 그 홀 정산과 **다음 홀 배율**을 확인 → `다음 홀`
4. 마지막 홀(또는 메뉴의 `라운드 종료`) 뒤 요약 화면에서 `텍스트 복사` / `결과 카드 공유`

입력을 잘못했으면 결과 화면의 `이 홀 수정`, `홀 취소`, 또는 요약 화면의 `마지막 홀 점검 · 수정`을 쓰면 됩니다.

## 파일 구조

```
index.html            빌드 결과(앱 전체가 이 파일 하나에 들어 있음)
manifest.webmanifest  PWA 매니페스트
sw.js                 서비스 워커(캐시 우선 → 오프라인 실행)
icons/                앱 아이콘(180/192/512, maskable)
src/rules.js          규칙 엔진(순수 함수, DOM·저장·네트워크 없음)
src/store.js          localStorage + IndexedDB 저장
src/app.js            화면
src/style.css         스타일
src/index.template.html
tools/build.py        src → index.html 합치기
tools/make_icons.py   아이콘 생성
tests/test_rules.py   규칙 단위 테스트 (102개 검증)
tests/test_browser.py 실제 헤드리스 크로미움(390×844) 조작 테스트 + 스크린샷
screens/              테스트에서 저장한 화면 캡처
```

## 개발

```bash
python3 tools/build.py          # index.html 재생성 (src 수정 후 필수)
python3 tests/test_rules.py     # 규칙 검증
python3 tests/test_browser.py   # 실제 브라우저에서 라운드 진행·새로고침·되돌리기·수정·오프라인 검증
```

`tests/test_browser.py`는 `playwright`와 크로미움 실행 파일이 필요합니다
(`tests/browser_util.py`의 `CHROME`, `LIBS` 경로).

## 배포

`main` 브랜치 루트가 그대로 GitHub Pages로 올라갑니다(상대 경로 `./` 사용).
`index.html`을 고친 뒤 커밋·푸시하면 1~2분 안에 반영됩니다.
아이폰 홈 화면 아이콘은 서비스 워커 캐시 때문에 즉시 바뀌지 않을 수 있습니다 —
그럴 때는 사파리에서 페이지를 새로 열거나 아이콘을 지웠다가 다시 추가하세요.
